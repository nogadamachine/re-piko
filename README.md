# re-piko

Instagram 449.0.0.52.84 안정 버전을 위한 Instagram 전용 Piko 패치입니다. 내부 개정은 r40, 패치 묶음 버전은 0.1.0-dev.2입니다. 설정과 패치 설명을 한국어로 제공합니다. X와 Twitter 전용 패치, 확장 코드 및 리소스는 포함하지 않습니다.

## Morphe에 추가

Morphe의 패치 소스 화면에서 + 버튼을 누르고 원격 소스로 아래 저장소 주소를 입력하세요.

```text
https://github.com/nogadamachine/re-piko
```

[Morphe에서 소스 추가](https://morphe.software/add-source?github=nogadamachine/re-piko&name=re-piko) 링크도 사용할 수 있습니다. [최신 릴리스](https://github.com/nogadamachine/re-piko/releases/latest)에서 MPP 파일을 직접 내려받아 로컬 소스로 가져올 수도 있습니다.

대상 원본은 Instagram 449.0.0.52.84의 arm64-v8a, Android 9.0+, 120-480dpi 버전입니다. 이 공개 배포에는 원본 Instagram APK 또는 APKM을 포함하지 않습니다. 원본은 [APKMirror의 해당 버전 페이지](https://www.apkmirror.com/apk/instagram/instagram-instagram/instagram-449-0-0-52-84-release/)에서 별도로 준비해야 합니다.

Instagram에는 re-piko 소스 하나의 패치만 선택하세요. 기존 Piko를 유지하려면 Clone 패치를 사용하고 다른 패키지 이름으로 설치하세요. 기존 설치와 서명이 다른 APK를 기존 앱 위에 설치하거나 기존 앱을 삭제하면 데이터가 유지되지 않을 수 있습니다.

## 포함된 기능

익명 스토리 보기, DM 읽음 숨김과 수동 읽음 처리, 사진과 동영상 저장, 광고와 추천 영역 제어, 분석 차단, 좋아요와 인터페이스 제어 및 사용자 글꼴 등의 Instagram 패치를 포함합니다. Clone 구성에서 61개, Default 구성에서 60개 패치를 적용했습니다.

저장 가능한 서버 미디어 후보의 가로와 세로 해상도를 비교해 가장 큰 후보를 선택합니다. 동영상은 다시 인코딩하지 않고 MP4로 저장합니다. JPEG 원본은 바이트 복사하고, WebP는 크기를 줄이지 않은 JPEG 품질 100으로 한 번 변환합니다. WebP에서 JPEG로 변환할 때 완전 무손실을 보장하지는 않습니다.

## 스토리 조회자 표시

`기타 > 스토리 조회자 아이디와 이름 표시` 설정을 추가했습니다. 기본값은 켜짐입니다. 기존 스토리 조회자 목록과 새 디자인의 조회자 행에서 `@아이디`와 이름을 두 줄로 표시합니다. 이름이 없거나 아이디와 같으면 아이디만 표시하며, 설정을 끄면 Instagram 원래 표시로 돌아갑니다. 조회자 응답에 이미 들어 있는 공개 프로필 정보만 사용하고 계정 유형, 공개 범위와 조회 기록을 바꾸지 않습니다.

개인 계정과 비공개 계정의 프로페셔널 상세 인사이트는 포함하지 않습니다. 인사이트 화면을 직접 여는 실행 검사에서 통계를 불러오지 못했습니다. 태그 클릭 수, 이동 경로, 도달과 반복 조회 같은 통계의 서버 제공이나 접근 권한을 패치로 확인하지 못했으므로 이를 추정하거나 0으로 대체하지 않습니다.

## 확인된 변경과 검증

r38은 광고 차단을 꺼도 Instagram 원래 함수가 실행되지 않던 결함을 수정했습니다. 켜면 차단 분기로 들어가고 끄면 원본 187개 명령과 처리 콜백으로 돌아갑니다. 두 APK의 원래 함수 보존 검사 11개와 설치된 에뮬레이터 앱의 OFF, ON, 다시 OFF 분기 실행을 통과했습니다. 이 분기 검사는 의도적인 null 입력을 사용하며 실제 광고 노출과 서버 동작을 증명하지는 않습니다.

r38 전체 Android 릴리스 빌드와 원본 APKM 패치 적용이 성공했습니다. Clone 60개, Default 59개 중 실패한 패치는 0개입니다. 두 APK의 구조, 서명, 참조, 실행 오류 회귀, DM 읽음 보호와 글꼴 흐름 검사를 통과했습니다. 두 구성 모두 에뮬레이터 설치, Android 실행 코드 검사와 정상 시작을 확인했습니다. 추가 범용 lint 검사는 r37에서 로컬 의존성이 없어 실패했으며 Android 릴리스 빌드 성공과 구분합니다.

변경되지 않은 기능은 실제 검증 개정을 유지합니다. r37 실기기 검사에서 글꼴 그리기 윤곽 21개 일치와 원래 굵기 유지를 확인했고, 실제 스토리 Classic과 Modern 편집 스타일은 적용 전, 적용 후, 삭제 후 여섯 단계에서 유지됐습니다. r35 실기기 검사에서 익명 스토리의 실제 조회자 목록 대조와 DM 읽음 숨김 및 수동 읽음 처리를 확인했습니다. r37 분석 차단은 릴스 재생 후 native 이벤트 목록 OFF 6개, ON 0개, 다시 OFF 8개로 대조했습니다.

r40의 새 조회자 표시 기능은 설치 앱에서 합성 프로필 자료로 표시와 설정 복원 12개 검사, 기존 목록과 새 디자인의 실제 행 레이아웃 2개 검사를 통과했습니다. 실제 서비스의 비공개 스토리 조회자 목록 대조는 완료하지 않았습니다. r40 전체 기능의 실기기 재검증은 수행하지 않았습니다. 실기기 검사 결과는 r35와 r37의 확인 범위입니다.

## 남은 검증 조건

아래 항목은 실제로 시도했지만 기능 효과를 확정하는 원래 상태 대조를 얻지 못했습니다. 코드 검사와 구분하며 완전히 검증됐다고 표시하지 않습니다.

- 광고 차단: OFF에서도 실제 광고가 나타나지 않아 같은 화면의 광고 제거 효과를 대조하지 못했습니다.
- 라이브 익명 시청: 테스트 게시자 계정이 라이브 시작 자격 조건을 충족하지 못했습니다. 익명 스토리 보기의 조회자 목록 대조는 별도로 확인했습니다.
- 외부 링크 오류 수정: 정상 외부 링크 실행과 입력 검사는 통과했으나 과거 종료 오류를 재현하지 못했습니다.
- 오래된 버전 알림 제거: 실제 오프라인 상태에서 30일 미래 시각으로 시작했으나 원래 만료 팝업이 나오지 않았습니다.
- 직원용 디버깅 옵션: 설치 플래그와 실제 ID 연결 검사는 통과했으나 직원 메뉴가 원래 나타나는 자격과 화면 조건을 확보하지 못했습니다.
- 하단 빈 공간 제거: 실제 탐색 막대와 inset을 바꾸어 대조했으나 OFF 상태에서도 원래 빈 공간이 나타나지 않았습니다.

일부 미디어 종류, 실제 디코딩된 최대 해상도, 스크린샷의 상대 알림, 전체 Meta 인증서 통신과 분석 전송 경로에는 검증 한계가 남아 있습니다. 정상 시작 로그의 주요 치명 오류 패턴은 발견되지 않았으나 모든 네이티브 경고를 해결했다고 주장하지 않습니다. 사진 스토리 필터 문제는 이번 완료 범위에서 제외했습니다. Visited Accounts 기능은 포함하지 않았습니다.
